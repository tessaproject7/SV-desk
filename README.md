# SV desk

This repository hosts the SV desk iPhone web app (PWA).

The app is served from the repository root: `index.html`, `app.css`, `app.js`, `chart.js`, `sw.js`, and `manifest.json`, with sample fixtures in `proof/`, `proof_empty/`, and `proof_error/`.

Sample screens:

- `?proof=1` shows a filled sample desk
- `?proof=empty` shows an empty desk
- `?proof=error` shows the offline error screen
